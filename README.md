# Hi, I'm Waralee 👋

I'm a Master of Data Science student at Swinburne University, interested in data analytics, machine learning, and practical application prototypes.

I work mainly with Python and R, from data preparation and exploratory analysis through modelling, evaluation, and lightweight application development.

## Selected work

### [Sentiment classification with Linear SVM](https://github.com/waraleesridokmai/sentiment-classification-linear-svm) — solo university project

Sanitized, reproducible rebuild of a text-classification assignment using 3,000 Amazon, IMDb, and Yelp sentences from UCI. A duplicate-aware grouped split and TF-IDF unigram/bigram pipeline achieved mean five-fold CV F1 of 0.798 and held-out F1 of 0.864.

`Python` · `pandas` · `scikit-learn` · `NLP` · `data quality`

### [NexStep](https://github.com/waraleesridokmai/nexstep) — application prototype

AI-assisted Flutter prototype for short, structured self-experiments: create a sprint, record daily text or photo check-ins, and receive coaching-style feedback. The public version defaults to offline demo mode and documents the proposed Supabase architecture and production limitations.

`Flutter` · `Dart` · `Riverpod` · `Supabase` · `mobile UX`

### [Victorian crash severity and hotspot analysis](https://github.com/ppraeeprae/vic-crash-analysis) — team project

Analysis of nine joined Victorian road-crash datasets using R to model crash severity and map spatial hotspots. I contributed data preparation, project restructuring, severity-analysis reporting, and analysis refactoring.

`R` · `tidyverse` · `sf` · `spatial analysis` · [my commits](https://github.com/ppraeeprae/vic-crash-analysis/commits?author=waraleesridokmai)

### [Enron email extraction and sentiment analysis](https://github.com/dylannguyen2001/COS70008) — team project

Data pipeline for extracting the Enron email corpus and producing email- and thread-level sentiment outputs. I contributed the email extraction workflow, sentiment-analysis pipeline, and standardized sentiment-score outputs.

`Python` · `Jupyter` · `NLP` · `data pipelines` · [my commits](https://github.com/dylannguyen2001/COS70008/commits?author=waraleesridokmai)
